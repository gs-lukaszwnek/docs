# SDK

Documentation for the JavaScript SDKs used with Gainsight Customer Communities:

| SDK | Purpose |
|-----|---------|
| **[Widget SDK](widget-sdk/overview)** | Call [connectors](/connectors/) from custom widget code. Use this when building widgets that need to talk to external APIs. |
| **[Web SDK](web-sdk/overview)** | Interact with the community page from widgets or scripts: search content, users, subscriptions, DOM, and lifecycle. |

The word "SDK" refers to three different things in these docs — see [SDK Concepts](/sdk/concepts) for how they differ.

Choose the section in the sidebar to get started.
