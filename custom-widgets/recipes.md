# Recipes

Step-by-step guides for common Extensions scenarios — publishing and operating widgets, scripts, and stylesheets from your Git repository. Use these recipes when you already have a specific goal, like testing changes safely or forcing a rebuild, rather than learning the platform from scratch.

## Development Workflows

| Recipe | Description |
|--------|-------------|
| [Preview and Promote](preview-and-promote) | Test changes with a separate staging community, then promote by merging |

## Advanced Operations

| Recipe | Description |
|--------|-------------|
| [Force Republish](force-republish) | Trigger rebuild without code changes |

## Prerequisites

Before using these recipes, ensure you have:

* A GitHub account connected to the platform ([Connect Your GitHub Account](../v2/connect-github))
* At least one repository enabled ([Repository & Branch Settings](../v2/repository-settings))
* Basic understanding of the registry file format ([Registry Reference](../v2/registry-reference))
