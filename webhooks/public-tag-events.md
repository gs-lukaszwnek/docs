# Public Tag Events

## Available public tag events

* [Tag.Created](#tag-created)

## Event payloads

### tag.Created

```json
{
    "id": "11063",
    "name": "Tag1",
    "createdBy": "2004"
}
```

* `id` tag id
* `name` tag name
* `userId` identifies the user who created the tag
