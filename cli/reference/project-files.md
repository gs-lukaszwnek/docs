# Project Files

Describes every path `gsds` touches. Commit rules are stated per file.

## In your project

### Committed

| Path | Purpose |
|---|---|
| `gsds.json` | Project-root marker. `gsds` refuses to run outside a directory containing this file, apart from `gsds init` |
| `extensions_registry.json` | Registry of widgets, scripts, and stylesheets in the project. Regenerated by `gsds build` |
| `connectors_registry.json` | Registry of Connectors and composite Connectors. Regenerated by `gsds build` |
| `AGENTS.md` | AI-agent-oriented project notes seeded by `gsds init` |
| `README.md` | Human-oriented project notes seeded by `gsds init` |
| `.gitignore` | Adds `.gsds/` to the ignore list |

### Not committed

| Path | Purpose |
|---|---|
| `.gsds/` | Connector-test capture output, with sensitive headers redacted. `gsds init` gitignores this directory |

### Read by `gsds build`

| Path | Requirements |
|---|---|
| `widgets/<name>/widget.json` | Must declare a non-empty `title` and `category`. Must declare exactly one of `source` or `content` |
| `widgets/<name>/connectors.json` | May declare `connectors` and/or `composite_connectors`. Permalinks must be unique across widgets |

Scripts and stylesheets do not have their own source manifests — their entries live only in `extensions_registry.json` and are edited through `gsds script` and `gsds style`.

## In your user account

### OS keychain

`gsds` stores the session token in your operating system's keychain:

| Platform | Backend |
|---|---|
| macOS | Keychain |
| Windows | Credential Store |
| Linux | Secret Service or keyutils via `@napi-rs/keyring` |

Service name: `gainsight-developer-studio-cli`. Account name: `default`.

### File fallback

When the keychain is unavailable — no supported provider, headless CI, or a keychain error — `gsds` writes to `~/.config/gsds/credentials.json` at file mode `0600` and prints a one-time warning on stderr.

## Environment variables

| Variable | Effect |
|---|---|
| `GSDS_DISABLE_KEYCHAIN=1` | Force the file-based credential fallback even when a keychain is available |
